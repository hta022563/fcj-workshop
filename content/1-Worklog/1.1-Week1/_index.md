### Week 1 Objectives:

* Onboard with the First Cloud AI Journey program, understand AWS Global Infrastructure, and interact via Console, CLI, and API.
* Master the AWS Shared Responsibility Model and essential steps for locking down the Root User.
* Practice identity management with AWS IAM (Users, Groups, Roles, Policies, Permission Boundaries) using Least Privilege.
* Configure AWS Budgets cost alerts and perform clean teardown of temporary lab resources.
